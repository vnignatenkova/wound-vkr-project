# Применение анализа изображений для оценки ран

## Описание проекта

Проект посвящён разработке программного подхода к анализу изображений ран на основе методов компьютерного зрения и машинного обучения. Основная цель состоит в том, чтобы по фотографиям ран получать формализованное признаковое описание, анализировать динамику раневого процесса и строить модель прогноза заживления.

В текущей версии проекта реализован воспроизводимый pipeline, включающий:
1. визуальную проверку и обработку разметки изображений;
2. извлечение признаков из изображений ран;
3. построение динамических признаков;
4. анализ информативности признаков;
5. выбор оптимального компактного набора признаков;
6. обучение итоговой модели прогноза;
7. формирование итоговых предсказаний и отчёта.

## Структура проекта

Основные скрипты:
- `segmentation.py` — визуальная проверка разметки и подготовка данных;
- `extract_wound_features.py` — извлечение признаков из изображений;
- `build_wound_dynamics.py` — построение динамических признаков;
- `analyze_feature_significance.py` — анализ значимости признаков;
- `compare_feature_sets.py` — сравнение различных наборов признаков;
- `prune_feature_sets.py` — сокращение признакового пространства;
- `train_compact_healing_model.py` — обучение итоговой модели;
- `predict_compact_healing_model.py` — получение предсказаний;
- `build_compact_healing_report.py` — формирование итогового отчёта.

Основные данные:
- `wound_image_features.csv` — признаки отдельных изображений;
- `wound_phase_dynamics.csv` — динамические признаки;
- `wound_forecast_dataset.csv` — итоговая таблица для прогнозирования.

Основные результаты:
- `feature_significance_analysis/`
- `feature_set_comparison/`
- `feature_pruning_analysis/`
- `compact_healing_model/`
- `compact_healing_predictions/`
- `compact_healing_report/`
